# Fingerprint Recognition

Учебный проект по сравнению отпечатков пальцев с использованием сиамской нейронной сети.

## Описание проекта

Проект предназначен для определения сходства двух изображений отпечатков пальцев. Нейронная сеть обучается сравнивать пары изображений и оценивать, принадлежат ли они одному человеку.

## Основные возможности

- Подготовка и обработка изображений отпечатков пальцев
- Обучение сиамской нейронной сети
- Сравнение пар изображений
- Оценка сходства по расстоянию между полученными представлениями изображений

## Технологии

- Python
- TensorFlow / Keras
- NumPy
- Обработка изображений
- Сиамские нейронные сети

## Статус проекта

Учебный проект.
