# Fingerprint Recognition

Учебный проект по сравнению отпечатков пальцев с помощью сиамской нейронной сети.

## О проекте

В проекте реализована модель, которая сравнивает два изображения отпечатков пальцев и оценивает степень их сходства. Для этого изображения подготавливаются к обучению, после чего сеть обучается сравнивать пары образцов.

## Что реализовано

- Подготовка изображений и нормализация данных
- Обучение сиамской нейронной сети
- Сравнение пар отпечатков пальцев
- Проверка результатов на тестовых изображениях

## Технологии

Python, TensorFlow, Keras, NumPy.

## Статус

Учебный проект.
